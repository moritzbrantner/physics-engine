Physics settings

The bounded f64 solver runs four substeps with up to eight contact iterations each. Two bounded geometric passes correct residual overlap with fixed colliders without adding velocity. Rust owns movement, swept projectile contacts and sleeping. Settings are validated by the shared foundation.

Legacy event stepping remains available on the solver comparison page; it can still fail on rotating stacks. This tower always uses fixed-step physics. Sweeps approximate rotation within each substep.
