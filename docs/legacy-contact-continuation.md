The dense-contact churn arose when iterative integer projection separated an already admitted pair by one position quantum. Free flight under gravity closed that rounding gap and spent another chronological impact event on the same support. During one repeated-event advance, retain only pairs present in a strictly admitted rigid contact frontier. Only persistent pairs with a minimum half-extent of at least 1024 position units in both bodies qualify: one quantum is at most 2^-10 of each shape. Coarser shapes and transient impacts retain the original strict release rule. For qualifying pairs, expand each box half-extent by one integer position unit solely to decide whether support has actually separated. A clear sample outside this band releases the pair; the original strict SAT clear/contact search and refinement then admit any returning impact. An initially separated stale pair gets normal swept eligibility. No continuation survives the requested interval.

It does not change strict contact admission, penetration assertions, broad-phase bounds, wake evidence, impulses, restitution, sample/refinement counts, solver passes or the event cap.
